# Project Overview

**Project Name:** Life Calendar
**Type:** Monolith Web Application
**Architecture:** Layered Component Architecture

Life Calendar is a SaaS application for visualizing life events on a temporal grid, inspired by the "Life in Weeks" concept. It allows users to gain a perspective on their life span by marking events and periods on a highly visual calendar.

## Technical Summary

| Category | Technology |
| :--- | :--- |
| **Framework** | Next.js 16.1.1 |
| **Language** | TypeScript |
| **UI** | React 19, Tailwind CSS v4 |
| **State** | React Context |

## Repository Structure

The project is a single monolithic repository structured around the Next.js App Router conventions.

- **`src/app`**: Application routes and pages.
- **`src/components`**: Reusable UI and feature components.
- **`src/lib`**: Core logic and helpers.
